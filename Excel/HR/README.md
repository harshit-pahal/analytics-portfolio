HR Employee Records Project

🎯 Goal
Analyze employee data to uncover HR insights like attrition, salary trends, and performance distribution.

🧹 Data Cleaning Steps
- Removed duplicate Employee IDs.
- Standardized missing values (`BLANK, #N/A` → `Unknown`).
- Fixed inconsistent department and job titles.
- Converted dates to proper format.
- Ensured numeric columns (Salary, Rating) are valid.

📊 Analysis Performed
- KPIs: Total Employees, Active vs Terminated, Average Salary, Attrition %.
- Pivot Tables: Department‑wise headcount, salary averages, performance ratings.
- Dashboard (coming next): Interactive charts and slicers for HR insights.

📁 Files Included
- `RAW_HR_Employee_Records.csv` → Raw dataset.
- `CLEANED HR RECORD.xlsx` → Cleaned dataset.
- `HR_KPI_Pivots.xlsx` → KPI formulas and pivot tables (to be added).
- `HR_Dashboard.xlsx` → Final dashboard (to be added).
